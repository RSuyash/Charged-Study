# 2.2.1.3 Maintenance of Primary Cell Culture

Maintaining [[2.2.1 Primary Cell Culture|primary cell cultures]] requires careful attention to culture conditions and regular monitoring due to their [[3.1.1 Primary Cell Lines|finite lifespan]] and specific needs. [[2.1 Basic Aseptic Techniques|Aseptic technique]] is paramount.

## Key Aspects of Maintenance

1.  **Culture Medium and Supplements:**
    *   **Appropriate Medium:** Use a [[2.1.2.3 Cell-Specific Media|cell-specific medium]] optimized for the primary cell type.
    *   **Serum:** If using [[2.1.2.1 Serum-Dependent Media|serum-supplemented media]], use high-quality, characterized serum (e.g., FBS) at appropriate concentrations (5-20%). Consider serum-reduced or [[2.1.2.2 Serum-Independent Media|serum-free]] alternatives if possible.
    *   **Growth Factors/Additives:** Supplement with essential growth factors, hormones, cytokines, attachment factors specific to the cell type. Optimize concentrations.
    *   **Fresh Media:** Prepare fresh media using high-purity water/components. Store appropriately, aliquot supplements to avoid freeze-thaw cycles.

2.  **Incubation Conditions:**
    *   **Temperature:** Maintain optimal temperature (usually 37°C ± 0.5°C for mammalian cells) using calibrated [[1.2.2 CO2 Incubator|incubators]]. See [[2.1.3.4 Temperature Control]].
    *   **CO₂:** Maintain appropriate CO₂ (typically 5%) if using [[Bicarbonate Buffer]]. Monitor levels. See [[2.1.3.2 CO2 and Bicarbonate Regulation]].
    *   **Humidity:** Maintain high humidity (>90%) to prevent media evaporation.
    *   **Sterility:** Maintain strict aseptic technique.

3.  **Subculturing (Passaging) and Density Management:**
    *   **Limited Lifespan:** Track passage number; use cells within their optimal range before senescence.
    *   **Subculture Timing:** Passage before cells become overconfluent (typically 70-90% confluency for adherent cells) to prevent contact inhibition, nutrient depletion, waste accumulation.
    *   **Gentle Cell Detachment:** Minimize cell damage.
        *   *Enzymatic:* Trypsin-EDTA, Accutase. Optimize concentration/time. Neutralize enzyme activity.
        *   *Mechanical:* Cell scrapers, pipetting for loosely adherent cells.
    *   **Seeding Density:** Seed at an appropriate, optimized density for healthy growth.
    *   **Regular Media Changes:** Replenish nutrients, remove waste (typically every 2-3 days). Adjust frequency based on cell type, growth rate, density.

4.  **Monitoring Culture Health and Viability:**
    *   **Microscopic Examination:** Regularly check morphology, confluency, signs of contamination/stress using [[1.2.3 Microscopes]].
    *   **[[2.2.1.2 Viable Cell Count Methods|Viable Cell Counts]]:** Periodically monitor growth rate and viability (e.g., Trypan Blue).
    *   **pH Monitoring:** Check media pH (phenol red indicator or pH meter).
    *   **Contamination Checks:** Regularly check for bacteria, fungi, mycoplasma (visual, microscopic, specific assays like PCR).

5.  **Preventing Microbial Contamination:**
    *   **Strict Aseptic Technique:** Essential. Work in [[1.2.1 Laminar Flow Hoods]], use sterile materials/reagents, proper [[PPE]].
    *   **Sterile Media/Reagents:** Use certified sterile supplies. Filter sterilize if needed ([[1.3.1 Filters]]).
    *   **Antibiotics/Antimycotics:** Use judiciously. Can mask contamination, select for resistance, affect cell physiology. Avoid in long-term cultures/bioproduction if possible.
    *   **Regular Cleaning:** Clean/disinfect incubators, hoods, equipment regularly.

6.  **[[Cryopreservation]] for Long-Term Storage:**
    *   **Purpose:** Preserve finite primary cells for long-term use, create cell banks.
    *   **Cryoprotective Agents:** Use DMSO or glycerol in freezing media to prevent ice crystal damage.
    *   **Controlled Freezing Rate:** Slow cooling (e.g., -1°C/min) using controlled-rate freezer or protocol.
    *   **Proper Thawing:** Thaw rapidly (37°C water bath), dilute out cryoprotectant gradually.

Careful control of these aspects is crucial for maintaining healthy, functional primary cell cultures, acknowledging their limited lifespan and specific requirements.
