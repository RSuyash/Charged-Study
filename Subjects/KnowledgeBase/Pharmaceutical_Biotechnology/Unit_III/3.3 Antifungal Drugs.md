# 3.3 Antifungal Drugs

Antifungal drugs are a class of medications used to treat fungal infections. Fungal infections can range from superficial skin and mucous membrane infections to life-threatening systemic infections.

Key antifungal drugs discussed include:

-   [[3.3.1 Nystatin]]
-    Griseofulvin *(Note: While Griseofulvin is mentioned in the source, there is no separate section for it. The information is included in the Nystatin section, so I will not create a separate note for it.)*

These drugs target different aspects of fungal cell structure and metabolism.
